# KeepCool-DesertThreads

Digital Component to HXDI Thesis Project "DesertThreads"

This component involves educating farmworkers on heat safety and signs of heat illness. This is accessible through a QR code present on the garment that can be accessed at any time to review.

The project is based on my hometown, the people who uphold and define it, and the family who has supported me.
